2. Luồng Upload + Confirm Cloudinary

sequenceDiagram
    autonumber
    actor User as Client / Workbench
    participant Route as image_routes.py
    participant Svc as ImageService
    participant Repo as image_repo / Firestore
    participant Cld as Cloudinary

    User->>Route: POST /images/upload-url (Bearer uid, metadata)
    Route->>Svc: requestUpload(uid, filename, contentType, sizeBytes, provider="cloudinary")
    Svc->>Svc: checkFile(...) & tạo imageId (UUID)
    Svc->>Repo: save(doc với status="PENDING", currentFolder="upload")
    Repo-->>Svc: ok
    Svc-->>Route: {imageId, uploadUrl, cloudinaryConfig, image}
    Route-->>User: 200 OK

    User->>Cld: Upload ảnh trực tiếp lên Cloudinary (uploads/{uid})
    Cld-->>User: Trả về các publicId / URL biến thể

    User->>Route: POST /images/cloudinary/confirm (Bearer uid, 3 publicId & metrics)
    Route->>Svc: confirmCloudinaryUpload(...)
    Svc->>Svc: Kiểm tra đủ 3 publicId & checkFile(...)
    Svc->>Repo: get_by_id(image_id)
    alt Doc đã tồn tại
        Repo-->>Svc: existing doc
        Svc->>Svc: verifyOwner(existing, uid)
    else Doc chưa tồn tại
        Svc->>Svc: Khởi tạo doc mới cho uid
    end
    Svc->>Repo: save(doc với status="DONE", currentFolder="processed", variants, processingMs)
    Repo-->>Svc: ok
    Svc-->>Route: doc đã cập nhật
    Route-->>User: 200 OK

3. Luồng Sync Google Drive Pipeline & Cloudinary

sequenceDiagram
    autonumber
    actor User as Client / Workbench
    participant Route as image_routes.py
    participant Svc as ImageService.syncExternalImages
    participant Repo as image_repo
    participant Drive as GoogleDriveService
    participant Cld as cloudinary_service

    User->>Route: POST /images/sync?folderId=... (Bearer uid)
    Route->>Svc: syncExternalImages(uid, root_folder_id)
    Svc->>Repo: list_by_owner(uid)
    Repo-->>Svc: existing_docs (lọc known_drive_ids & known_cloud_ids)

    Svc->>Drive: list_all_pipeline_images(uid, root_folder_id)
    alt Đã liên kết Google Drive
        Drive->>Drive: ensure_pipeline_folders(uid, root_folder_id)
(root -> upload, processing, processed)
        Drive-->>Svc: danh sách file ảnh theo stage (PENDING / PROCESSING / DONE)
        loop Với mỗi file Drive mới
            Svc->>Repo: save(doc với imageId="drive_", provider="google_drive", previewUrl="/images/preview/")
        end
    else Chưa đăng nhập / chưa liên kết Drive
        Drive-->>Svc: Exception (bỏ qua an toàn)
    end

    Svc->>Cld: list_images(prefix="uploads/{uid}") (fallback prefix="" nếu rỗng)
    Cld-->>Svc: danh sách file ảnh Cloudinary
    loop Với mỗi asset Cloudinary mới
        Svc->>Repo: save(doc với provider="cloudinary", status="DONE", variants)
    end

    Svc-->>Route: {syncedFromGoogleDrive, syncedFromCloudinary}
    Route->>Svc: listImages(uid, auto_sync=False)
    Svc->>Repo: list_by_owner(uid)
    Repo-->>Svc: items
    Route-->>User: 200 OK ({sync, ownerId, total, items})

4. Luồng xóa ảnh DELETE /images/{image_id}

sequenceDiagram
    autonumber
    actor User as Client / Workbench
    participant Route as delete_image_endpoint
    participant Svc as ImageService.delete_image
    participant FS as Firestore
    participant Cld as Cloudinary Admin API
    participant Drive as GoogleDriveService

    User->>Route: DELETE /images/{image_id} (Bearer uid)
    Route->>Svc: delete_image(uid, image_id)
    Svc->>FS: GET images/{image_id}

    alt Không tồn tại
        FS-->>Svc: not exists
        Svc-->>Route: ImageNotFoundError
        Route-->>User: 404 Not Found
    else ownerId != uid
        FS-->>Svc: doc (khác ownerId)
        Svc-->>Route: ForbiddenImageError
        Route-->>User: 403 Forbidden
    else provider == "cloudinary"
        Svc->>Svc: extract_three_public_ids(doc, image_id)
        Svc->>Cld: delete_resources(public_ids)
        alt Lỗi / 429 / Timeout / 5xx
            Cld-->>Svc: AdminError / AdminRateLimited / AdminUnavailable
            Svc-->>Route: raise exception
            Route-->>User: 503 Service Unavailable (giữ nguyên Firestore)
        else Xóa thành công
            Cld-->>Svc: deleted / not_found
            Svc->>FS: WriteBatch commit
(delete images/{id}, delete cloudinaryAssets/{sha256},
set uploadGrants/{id}.status = "DELETED")
            FS-->>Svc: committed
            Svc-->>Route: None
            Route-->>User: 204 No Content
        end
    else provider in {"google_drive", "drive"}
        Svc->>Svc: _extract_drive_file_id(doc, image_id)
        Svc->>Drive: delete_file(uid, drive_file_id)
        alt Lỗi Drive API (trừ 404 coi như đã xóa)
            Drive-->>Svc: AdminUnavailable
            Svc-->>Route: raise exception
            Route-->>User: 503 Service Unavailable (giữ nguyên Firestore)
        else Xóa hoặc 404
            Drive-->>Svc: ok
            Svc->>FS: WriteBatch commit
(delete images/{id}, cập nhật uploadGrants/{id} nếu tồn tại)
            FS-->>Svc: committed
            Svc-->>Route: None
            Route-->>User: 204 No Content
        end
    else Provider khác
        Svc-->>Route: UnsupportedProviderError
        Route-->>User: 400 Bad Request
    end

6. Bảng ánh xạ trạng thái & mô hình dữ liệu chính

Thành phần / Mã Vai trò hoặc ý nghĩa trong hệ thống
images/{imageId} Metadata ảnh (ownerId, provider, driveFileId, variants, status, currentFolder)
cloudinaryAssets/{sha256(public_id)} Bản ghi theo dõi từng asset Cloudinary, xóa cùng WriteBatch khi xóa ảnh
uploadGrants/{imageId} Grant upload; chuyển status = "DELETED" khi xóa để chặn confirm lại (409)
204 / 400 / 403 / 404 / 503 Xóa thành công / Provider không hỗ trợ / Sai chủ sở hữu / Không tìm thấy / Lỗi upstream giữ nguyên doc
